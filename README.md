# financial-management

회계 전표 관리 콘솔 프로그램입니다. 계정과목을 등록하고 거래를 전표로 기록·취소·조회하며, 전표를 집계해 자산·부채 현황을 확인합니다.

## 실행 방법

JDK 17이 필요합니다.

```bash
./gradlew run --console=plain    # Windows: gradlew.bat run --console=plain
./gradlew test                   # Windows: gradlew.bat test
```

## 1. 기능 목록

| 메뉴 | 기능 | 핵심 규칙 |
| --- | --- | --- |
| 1 | 계정과목 등록 | 코드는 3자리 숫자, 이름은 1~20자, 분류는 자산·부채·수익·비용. 중복 코드는 거절 |
| 2 | 계정과목 조회 | 코드 오름차순으로 출력 |
| 3 | 전표 작성 | 계정이 2개 이상 있어야 함. 차변·대변에 같은 계정은 거절. 금액은 1원~1,000,000,000원, 적요는 1~50자 |
| 4 | 전표 취소 | 차변·대변을 바꾼 취소 전표를 새로 만들고, 원전표는 상태만 `취소`로 변경. 중복 취소, 취소 전표의 취소, 원거래보다 이른 취소일자는 거절 |
| 5 | 전표 목록 조회 | 전표번호 순으로 출력 |
| 6 | 전표 상세 조회 | 차변·대변 계정과 금액 출력 |
| 7 | 자산·부채 현황 조회 | 취소된 원전표와 취소 전표를 포함해 모든 전표를 집계. 0원·음수 잔액을 그대로 출력하고, 수익·비용 계정은 목록에서 제외 |
| 0 | 종료 | 입력 스트림이 끝났을 때도 종료 |
| 공통 | 잘못된 입력 | `[ERROR]` 메시지를 출력한 뒤 같은 안내로 다시 입력받음. 실패한 요청은 전표번호를 소비하지 않음 |

## 2. 예상 결과

계정 `101 현금(자산)`, `201 차입금(부채)`, `401 용역수익(수익)`, `501 소모품비(비용)`이 등록된 상태를 기준으로 합니다.

| 구분 | 입력 | 예상 결과 |
| --- | --- | --- |
| 정상 거래 | `2026-11-06,운영자금 차입,101,201,100000`<br>`2026-11-06,사무용품 구입,501,101,10000`<br>`2026-11-06,용역대금 수령,101,401,30000` | 전표 1·2·3번 생성 |
| 잘못된 입력 | 계정 등록에서 `101,현금,자본` | `[ERROR] 계정 분류는 자산, 부채, 수익, 비용 중 하나여야 합니다.` 출력 후 같은 안내로 재입력 |
| 전표 취소 | `2,2026-11-07` | 2번 상태가 `취소`로 바뀌고, 차변 현금 / 대변 소모품비인 4번 취소 전표 생성 |
| 잔액 집계 | 메뉴 7 (취소 전 → 취소 후) | 자산 120,000원 → 130,000원, 부채 100,000원 → 100,000원 |

취소 후 자산이 늘어난 이유: 2번(현금 대변 10,000원)과 4번(현금 차변 10,000원)이 함께 집계되어 서로 상쇄되기 때문입니다.

## 3. 객체별 책임

| 객체 | 가진 정보 | 책임지는 규칙 |
| --- | --- | --- |
| `AccountCode` | 3자리 코드 | 코드 형식 검증, 코드순 정렬 |
| `AccountType` | 자산·부채·수익·비용 | 분류별 잔액 계산 (자산·비용: 차변 − 대변 / 부채·수익: 대변 − 차변) |
| `Account` | 코드, 이름, 분류 | 이름 길이 검증 |
| `Accounts` | 등록된 계정 목록 | 중복 코드 거절, 코드로 계정 찾기 |
| `Amount` | 금액 | 1원 ~ 1,000,000,000원 범위 검증 |
| `Voucher` | 번호, 거래일자, 적요, 차변·대변 계정, 금액, 구분, 상태, 원전표번호 | 같은 계정 거절, 적요 길이 검증, 취소 가능 여부 판단과 취소 전표 생성 |
| `Vouchers` | 작성된 전표 목록 | 전표번호 부여(저장된 수 + 1), 번호로 찾기, 계정별 차변·대변 누계 집계 |
| `BalanceSheet` | 자산·부채 계정별 잔액 | 자산·부채 계정만 담기, 분류별 합계 |
| `InputView`, `InputParser` | - | 입력 해석 (쉼표 분리, 날짜·금액·전표번호 변환) |
| `OutputView` | - | 출력 형식 (`[ERROR]`, `100,000원`, 원전표번호 없음 `-`) |
| `MenuController`, `AccountController`, `VoucherController` | - | 메뉴 흐름 연결, 잘못된 입력의 재입력 처리 |
